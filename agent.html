Identity

Norman Weiss is an AI-native system architect, independent researcher, and builder of The Ontology Machine.

Core product

The main product is The Ontology Machine, a local-first Windows system for document ingestion, semantic releases, corpus databases, query agents, ontology lenses, source tracing, and evidence-bound knowledge mining.

The public source is open core. Official Windows installers, updater packages, tested runtime bundles, productive installation, support, and customer-specific development are commercial offerings.
